# Focus Sense - Cross-Platform Pomodoro App
# Requirements and Dependencies

## System Requirements
- Node.js 16+ (recommended: 18+)
- npm 8+ or yarn 1.22+
- Java Development Kit (JDK) 11+ (for Android builds)
- Android Studio (for Android development)
- Git

## Installation Steps

### 1. Clone the repository
git clone <your-repo-url>
cd focus-sense

### 2. Install Node.js dependencies
npm install

### 3. Install Capacitor dependencies (for mobile builds)
npm install @capacitor/core @capacitor/cli @capacitor/android @capacitor/sqlite

### 4. For Android development, install:
# Android Studio: https://developer.android.com/studio
# Java JDK 11+: https://adoptium.net/

### 5. Initialize Capacitor (if building for Android)
npx cap init

### 6. Add Android platform (if building for Android)
npx cap add android

### 7. Sync Capacitor (after any changes)
npx cap sync

## Development Commands

### Web Development
npm run dev          # Start development server
npm run build        # Build for production
npm run preview      # Preview production build
npm run lint         # Run ESLint

### Android Development
npx cap sync android     # Sync web assets to Android
npx cap open android     # Open in Android Studio
npx cap run android      # Build and run on device/emulator

## Troubleshooting

### Common Issues:
1. Node version too old: Update to Node.js 16+
2. Android build fails: Ensure JDK 11+ and Android Studio are installed
3. SQLite plugin issues: Run `npx cap sync android` after installation
4. Permission errors: Use `sudo` on macOS/Linux if needed (not recommended)

### Clean Installation:
rm -rf node_modules package-lock.json
npm install

### Reset Capacitor:
npx cap clean
npx cap sync

## Platform-Specific Notes

### Windows:
- Install Node.js from nodejs.org
- Install Android Studio
- Install JDK from Oracle or OpenJDK

### macOS:
- Use Homebrew: `brew install node`
- Install Android Studio from developer.android.com
- Install JDK: `brew install openjdk@11`

### Linux (Ubuntu/Debian):
- Install Node.js: `curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash - && sudo apt-get install -y nodejs`
- Install JDK: `sudo apt install openjdk-11-jdk`
- Install Android Studio manually from developer.android.com
